## Core ownership

Core owns portable foundations, algebra, immutable structures, bounded
navigation, and framework-independent state transitions.

- Keep Core free of DOM, Vue, Terminal, Form, Temporal, Virtual, and Tabular
  vocabulary and dependencies.
- Reuse existing Sequence, Selection, Grid, Tree, geometry, range, ratio,
  revision, result, and retained-index primitives before adding a structure.
- Admit a new primitive only when at least two independent domains require the
  same semantics and complexity contract.
- Public collection APIs expose their real access and materialization cost.
- New hot operations require the performance design gate and a Core complexity
  contract.
