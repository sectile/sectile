# @sectile/chart

Renderer-neutral chart models, scales, projections, queries and interaction.

```sh
pnpm add @sectile/chart
```

Import runtime APIs from focused entries such as `@sectile/chart/model` and
`@sectile/chart/scale`. Browser and Vue integrations use `@sectile/dom/chart`
and `@sectile/vue/chart`; the application owns rendering.
