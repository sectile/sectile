## Virtual ownership

Virtual owns portable measurement data, extent indexes, layout state,
placement, anchoring, windowing, and incremental repair policy.

- Reuse Core geometry, sequence, range, grid, spatial, result, and revision
  primitives.
- Expose explicit indexed/view operations; do not emulate arrays with Proxy.
- Keep DOM measurement, observers, scrolling effects, and Vue rendering in
  hosts.
- Representation changes follow frozen crossover decisions and distinguish
  sparse repair from dense rebuild.
- Work bounds use the actual production partition, block, track, or page model.
