# @sectile/virtual

Renderer-neutral list, masonry, track-grid and spatial layout engines.

```sh
pnpm add @sectile/virtual
```

Import focused strategies such as `@sectile/virtual/linear-layout`.
`@sectile/dom/virtual` and `@sectile/vue/virtual/core` connect plans to browser
measurement, scrolling and rendering. The domain engine does not style elements.
