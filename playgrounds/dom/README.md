# DOM playground

Interactive witnesses for every public DOM facade: listbox, slider, calendar, tree-view,
text, combobox, and tree-grid.

```sh
pnpm --filter @sectile/playground-dom dev
```

Choose a demo from the top navigation. Each surface shows its supported keyboard input,
current revision state, and projected host effects. The URL hash links directly to a demo,
for example `#combobox` or `#tree-grid`.
