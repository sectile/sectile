## 어디서 시작할까

Sectile은 상호작용의 의미와 화면 출력을 분리합니다. 처음이라면 [실행 환경](/ko/guide/host-model)을 읽고, 필요한 유형을 이미 알고 있다면 [컴포넌트 목록](/ko/components/)에서 바로 찾아볼 수 있습니다.
