# 가상화 문서 이동

가상화는 독립된 의미 패키지인 `@sectile/virtual`이 담당합니다. 전용 사용 안내에서는 항목 ID와 배치 좌표를 나누고, 배치 방식별 구현과 DOM·Vue 연결을 각각 설명합니다.

먼저 [`@sectile/virtual` 개요](/ko/packages/virtual)를 읽고 [동작 원리](/ko/packages/virtual/concepts) 또는 [선형 목록 구현](/ko/packages/virtual/linear)으로 이어서 읽습니다.

이 페이지는 기존 주소를 새 가상화 문서로 연결하는 안내 역할을 합니다.
