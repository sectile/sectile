# 보장 범위

Sectile은 안정적인 식별자와 불변 상태 스냅샷을 사용하며, 자원 한도가 정해진 유한한 영역에서 결정적인 상호작용을 다룹니다.

## 보장하는 내용

- 안정적인 식별과 같은 입력에 대한 같은 관찰 결과
- 값 생성과 상태 변화에서 원인을 구분할 수 있는 오류
- 부모 관리 상태와 컴포넌트 자체 관리 상태
- 실패 시 원래 상태 보존과 오래된 변경 차수 거부
- 정확한 단계형 수치 범위와 경계가 있는 이동
- 순서가 있는 계층, 논리 좌표, 선택, 펼침과 일반 텍스트 편집
- 브라우저, 터미널과 프레임워크에서 같은 의미를 유지하는 동작

## 실행 환경이 맡는 내용

- 픽셀 위치, 화면 경계 회피, 배치와 애니메이션
- 브라우저 포커스, 포인터 캡처, 스크롤과 접근성 속성
- 터미널 현재 위치, 입력 해석과 표시 너비 계산
- 프레임워크 수명 주기, 컴포넌트 조합과 스타일
- 저장, 네트워크 요청과 제품 고유의 값 검증

## 별도 모델이 필요한 영역

다음 영역은 별도의 전용 모델이 담당합니다.

- 일반 그래프와 방향성 비순환 그래프 탐색
- 무한 자료 흐름과 처리량 제어
- 서식 있는 문서와 여러 사람이 함께 편집하는 텍스트
- 공간 좌표와 화면상 가장 가까운 항목으로 이동
- 서로 겹치거나 합쳐진 격자 영역

이 영역에는 고유한 관찰 결과, 법칙, 오류와 비용 계약이 필요합니다.
