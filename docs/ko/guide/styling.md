# 스타일 적용

Sectile 컴포넌트에는 시각 스타일이 들어 있지 않습니다. 화면에 그리는 각 요소에 클래스와 속성을 직접 붙여 원하는 모양을 만듭니다.

## 안정적인 선택자

프레임워크 컴포넌트는 `data-scope`, `data-part`, 상태 속성을 제공합니다. 빌드할 때마다 달라질 수 있는 클래스 이름보다 이런 의미 기반 속성을 사용하는 편이 안전합니다.

```css
[data-scope='checkbox'][data-part='root'][data-state='checked'] {
  background: var(--selected-background);
}
```

## 자식 요소에 동작 합치기

Vue 컴포넌트에는 일반 속성과 클래스를 그대로 전달할 수 있습니다. `asChild`를 지원하는 요소는 별도 감싸기 요소를 만들지 않고 하나뿐인 자식 요소에 동작을 합칩니다.

## 움직임

상태 속성을 기준으로 전환 효과를 적용합니다. 나타남과 사라짐을 모두 움직여야 한다면 해당 요소가 DOM에 남아 있어야 하는 시점을 명확하게 정합니다.
