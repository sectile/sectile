# 소개

Sectile은 여러 렌더링 환경에서 공유할 상호작용 규칙을 정의합니다. 같은 규칙으로 브라우저 화면, 터미널 프로그램, Vue 컴포넌트를 만들 수 있습니다. 실행 환경에 필요한 내용은 DOM, Terminal, Vue 패키지가 각각 맡습니다.

## Sectile이 맡는 일

- 상태 변화와 내부 상태 관리·외부 상태 관리 방식
- 이동, 선택, 펼침, 텍스트 편집, 수치 범위 규칙
- 포커스 이동, 안내 문구 읽기, 작업 실행처럼 실행 환경에서 처리할 명령
- 브라우저와 터미널 입력을 공통 규칙으로 바꾸는 처리

## 사용자가 맡는 일

- 색상, 간격, 배치, 움직임 같은 화면 디자인
- 자료 불러오기와 저장
- 제품에만 필요한 검증과 업무 규칙

## 패키지 구성

`@sectile/core`는 모든 실행 환경이 공유하는 규칙을 담습니다. `@sectile/dom`과 `@sectile/terminal`은 브라우저와 터미널 입력을 해당 규칙으로 연결합니다. `@sectile/vue`는 시각 디자인을 애플리케이션이 소유하는 Vue 컴포넌트로 이 동작을 제공합니다.

[이론](/ko/theory/)에서는 모든 패키지에서 동일하게 유지되는 구조, 상태, 상태 전이, 조합 원리를 설명합니다.
