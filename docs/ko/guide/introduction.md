# 소개

Sectile은 상호작용 동작을 명세하고 검증하는 시스템입니다. 현재 사실을 상태로 표현하고, 입력을 의미 사건으로 나타내고, 다음 상태와 순서 있는 작업을 계산합니다.

탐색, 선택, 펼침, 텍스트 편집, 폼, 달력 날짜, 표 형식 데이터, 차트, 가상화 컬렉션에 같은 모델을 적용합니다. 각 도메인은 유효한 값, 연산, 결과, 실패, 비용 상한을 공개 계약으로 정의합니다.

## 상태 전이가 동작하는 방식

1. 모델이 유효한 구조와 값을 정의합니다.
2. 상태가 현재 항목, 선택, 펼침, 텍스트 같은 사실을 기록합니다.
3. 사건이 이동, 선택, 삽입, 검증, 제출 같은 작업을 표현합니다.
4. 정책이 사용 가능 여부와 경계 동작 같은 선택을 제공합니다.
5. 전이가 새 불변 상태와 순서 있는 명령을 함께 반환합니다.

거절된 사건은 기존 상태와 명령 목록을 유지하면서 형식이 있는 오류를 반환합니다. 이 실패 원자성 규칙 덕분에 부분적으로 바뀐 상태 없이 모든 결과를 확인할 수 있습니다.

## 도메인별 책임

- **Core:** 순서, 범위, 격자, 계층, 상태, 전이, 명령의 기반
- **Form:** 필드 경로, 값, 검증, 오류, 제출, 초기화
- **Temporal:** 달력 날짜, 하루 안의 시각, 범위, 달력 규칙
- **Tabular:** 열, 행 접근, 그룹, 선택, 데이터 질의
- **Virtual:** 컬렉션 크기, 배치, 측정, 앵커 보정
- **Chart:** 불변 차트 모델, 척도, 투영, 질의

[패키지 지도](/ko/packages/)에서 도메인별 공개 경계를 확인할 수 있습니다. [코어 이론](/ko/theory/)은 공통 구조, 법칙, 실패 의미, 조합 모델을 설명합니다.
