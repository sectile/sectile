# 실행 환경

코어는 동작의 의미를 정의하고, 각 실행 환경은 실제 입력을 그 의미로 바꾸고 결과를 화면에 반영합니다.

## 코어

상태, 상태 변화, 업무 규칙, 오류, 실행 명령을 순수한 자료로 다룹니다. 같은 자료가 브라우저, 터미널, 프레임워크, 스타일 경계를 지나며 유지됩니다.

## 브라우저

키보드, 포인터, 포커스, 한글 조합 입력, 폼 제출, 접근성 속성을 처리합니다. HTML이 이미 정의한 동작은 브라우저 기본 방식에 가깝게 유지합니다.

## 터미널

터미널의 키 입력을 일정한 형태로 바꾸고, 커서 이동과 유니코드 문자 폭, 화면 출력을 처리합니다. 제품의 핵심 경계는 컴포넌트 연결 객체이며, 선택 기능인 화면 계층은 작은 참고 렌더러입니다. 컴포넌트 문서에서 터미널 환경을 선택하면 키보드로 직접 동작을 시험할 수 있습니다.

## 프레임워크

프레임워크 패키지는 코어의 동작 규칙을 유지하면서 생명주기와 컴포넌트 조합을 연결합니다.
