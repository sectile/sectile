# 코어 상태 전이와 조합

Core 컴포넌트는 현재 상태의 원본을 유지하며 다음 상태를 만드는 상태 기계입니다.

```text
상태 × 사건 → 결과<다음 상태 × 순서가 있는 명령>
```

같은 상태와 사건을 주면 같은 결과가 나옵니다. 포커스 이동, 스크롤, 알림, 실행 같은 작업은 순서가 정해진 명령 값으로 반환하고 실행 환경이 처리합니다.

## 갱신 순서

1. 명시적인 입력으로 상태를 만듭니다.
2. 의미가 정해진 사건 하나를 전달합니다.
3. 반환된 다음 상태를 한 번에 반영합니다.
4. 실행 환경 경계에서 명령을 순서대로 처리합니다.
5. 수락된 변경 차수를 밖에 알립니다.

앱이 상태를 관리할 때는 제안된 상태를 외부 값과 조정할 수 있습니다. 외부에서 소유할 값과 컴포넌트 내부의 진행 상태를 분리하면 타이머, 제스처, 종료 단계도 이어집니다. 변경 차수는 늦게 도착한 부모 갱신을 구분합니다.

## 조합

컴포넌트는 같은 작은 모델을 조합합니다. 달력은 격자 이동과 Temporal의 날짜 계산을 결합합니다. 가상 목록 상자는 Core에 전체 ID와 선택 상태를 두고 Virtual에는 실제로 그릴 항목만 묻습니다.

상세 법칙은 [상태 전이](/ko/theory/transitions), 컴포넌트 관계는 [조합 원리](/ko/theory/composition)에서 확인할 수 있습니다.
