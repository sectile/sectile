# Form API

Form은 Vue 컴포넌트용 API와 DOM 직접 연결용 API를 따로 제공합니다. 앱에서 가져오는 진입점에 맞는 문서를 선택하세요.

- `@sectile/vue/form`을 사용한다면 [Vue Form API](./vue/api)
- `@sectile/dom/form`을 사용한다면 [DOM Form API](./dom/api)

Vue 앱에서 저수준 DOM 연결 API까지 알 필요가 없도록 두 레퍼런스를 분리했습니다.
