# Bash 실습

브라우저 안에서 실제 Debian `/bin/bash`를 실행합니다. 컴퓨터에 별도 프로그램을 설치하지 않고 터미널 환경을 확인할 수 있습니다.

<BashPlayground />

## 무엇을 실행하나

- 수정하지 않은 Bash 실행 파일이 들어 있는 브라우저용 리눅스 가상 머신
- 가상 머신 콘솔과 연결한 xterm.js 터미널
- 컴퓨터의 셸이나 로컬 파일에 접근할 수 없는 격리 환경

컴포넌트 예시와 Bash 실습은 역할이 다릅니다. 각 컴포넌트 페이지는 `@sectile/terminal`에 직접 연결하고, 이 페이지는 실제 셸이 필요할 때만 사용합니다. Sectile은 `sectile` 명령을 설치하지 않습니다.

## 처음 시작할 때

처음 시작하면 격리용 서비스 워커를 등록하고 이 페이지를 한 번 새로 엽니다. 그다음 CheerpX 실행 환경과 Bash에 필요한 Debian 디스크 블록을 내려받습니다. 이후에는 브라우저 저장소를 재사용합니다.

Bash에서 `bash /sectile/check-environment.sh`를 실행하면 가상 머신에 설치된 실제 Bash와 Node 버전을 확인할 수 있습니다.
